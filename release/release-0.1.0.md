# Elvion 0.1.0

- 状态：未发布草稿。
- 发布日期：尚未发布；本次实现日期 2026-11-15。

## 新增功能

- 独立单 Agent 引擎、严格事件/错误/预算契约、可验证任务 DAG 与串行调度。
- 原生品牌字符 TUI、审批/权限/取消、CLI 与结构化输出。
- 十个 Phase 1 工具、四种模型协议、自定义供应商模板。
- Worker SQLite 事件/快照、保守恢复、独立验证和有限修复。
- 可独立 npm 打包的 CLI、品牌资源、Windows/Linux CI 和手工发布门禁。

## 修复与重要行为

首个版本，无既有公开版本迁移。工具执行通过统一权限入口；Windows Job Object 终止本地子进程树；未知副作用不自动重放。非交互待审批返回 3，超时返回 124，取消返回 130。

## 已知限制

- 正式 Windows Terminal 实际截图与其余真实供应商逐协议验收仍需补齐；一个 OpenAI-compatible 端点已通过真实编码闭环，详见 `docs/development-status.md`。
- 验证脚本发现当前支持 Node 项目；每个任务增量需可独立验证。
- 未提供 OS 沙箱、Multi-Agent、长期记忆、MCP、Web Research、并行工作区或高级容灾。
- 任意未知秘密不能保证自动识别；经授权 Shell 使用当前用户权限。
- 旧执行遗留锁和未知副作用需先核查。

## 升级与迁移

需要 Node.js 24 与 Git Bash。配置仅保存凭据环境变量引用。会话 Schema 带版本，不兼容数据明确拒绝，不自动迁移或删除。正式发布前应更新本文件日期和验收限制；本草稿不表示版本已经发布。
